ABOUT THE SYSTEM

Making Security Reporting Easier

The Borgu Security Incident Reporting System is designed to provide community members with a simple and reliable way to report security incidents.

Reports submitted through the platform can be accessed by authorized security agencies for review, investigation and appropriate action.

The system helps improve communication between communities and security agencies while supporting faster incident management.

HOW IT WORKS

Simple. Fast. Secure.

01

Create an Account

Register as a community user and securely log in to the system.

02

Submit a Report

Provide details about the security incident, including location, date, time, severity and description.

03

Agency Review

Authorized security agencies can access, review and update the status of submitted incident reports.
